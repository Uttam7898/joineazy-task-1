✨ Key Features Implemented

  • Role-Based Access Control (RBAC): Secure JWT-based authentication separating Student and Professor (Admin) roles.
  • Student Group Management: Students can create groups, search & invite peers by student email/ID, and manage members.
  • Assignment Distribution: Professors can post & edit assignments, configure OneDrive external submission links, and target all students or specific groups.
  • Two-Step Submission Verification: Guided confirmation ("Yes, I have submitted" → final verification) with prevention against accidental false marks.
  • Live Progress Tracking & Analytics: Visual progress bars, completion badges for groups, and interactive admin overview charts showing group & individual completion metrics.
  • Containerized Deployment: Production-ready docker-compose.yml setup orchestrating Frontend (Nginx), Backend (Express), and Database (PostgreSQL) with seed data.
